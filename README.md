# أثر (Athar)

تطبيق ويب إسلامي بيوفّر القرآن الكريم، التفسير، الأحاديث الصحيحة، والعقيدة،
مع مجتمع تفاعلي للمستخدمين.

## ✨ المميزات

- 📖 **القرآن الكريم**: قراءة كل السور بالرسم العثماني.
- 🔍 **التفسير**: بحث بالكلمة وجلب التفسير الميسّر.
- 📚 **الأحاديث**: أحاديث صحيحة من البخاري ومسلم.
- 👥 **المجتمع**: نشر منشورات والتفاعل مع المستخدمين.
- 👤 **حساب المستخدم**: تسجيل، تعديل البيانات، وجلسة آمنة.
- 📱 **متجاوب**: شغال على الموبايل والكمبيوتر.

## 🛠️ التقنيات

**Frontend:**
- HTML5, CSS3 (Flexbox + CSS Variables)
- JavaScript (Vanilla, Fetch API)
- Font Awesome + Google Fonts (Amiri Quran, Cairo)

**Backend:**
- Python 3
- FastAPI
- SQLite

**APIs خارجية:**
- [AlQuran Cloud](https://alquran.cloud/api) - القرآن والتفسير
- [UmmahAPI](https://ummahapi.com) - الأحاديث
